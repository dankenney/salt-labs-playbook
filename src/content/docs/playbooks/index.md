**At a glance → When to use → Inputs → Workflow → Prompts → Review checkpoints → Controls → Output template → Time-saving estimate**

Pages marked **Deep dive** are the highest-value workflows and are the most detailed. The rest are solid starting points that will deepen as teams use them.

:::caution[Advisory vs assurance]
Several playbooks describe advisory work (for example building an inventory or an evidence pack). If your team provides **assurance** to the same client, those services may be prohibited or restricted by independence rules. Check before you start. See [Independence considerations](/quality-risk/independence-assurance/).
:::
